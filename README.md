# Trabalho Final PDM

Aplicação Android desenvolvida em Kotlin para a unidade curricular de Programação para Dispositivos Móveis.

## Descrição

A aplicação permite consultar e gerir filmes, com autenticação, pesquisa, favoritos, reviews, perfil de utilizador e área de administração.

## Funcionalidades

- Registo e login
- Consulta e pesquisa de filmes
- Detalhes de filmes
- Favoritos
- Reviews
- Perfil de utilizador
- Área de administração

## Tecnologias

- Kotlin
- Android SDK
- Fragments + Navigation
- ViewBinding
- Ktor Client
- Room
- Coil

## Requisitos

- Android Studio
- Android 8.1+ (API 27)
- Backend a correr em `http://10.0.2.2:8080`

## Permissões

- INTERNET
- CAMERA
